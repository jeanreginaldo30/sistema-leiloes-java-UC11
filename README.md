Descrição

Repositório do Projeto de um sistema de Leilões desenvolvido em Linguagem Java com banco de dados MYSQL,segue neste mesmo repositório o código-fonte do Projeto java desevolvido no NetBeans.
Esse projeto permite o cadastramento e acompanhamento de Leiloes 

Tecnologias Utilizadas

NetBeans para codigficação do código java
MYSQL para Banco de Dados
